Git 仓库：https://github.com/LuciferTGQ/coding-agent.git

运行：Windows 用户从 GitHub Releases 下载并完整解压 CodingAgent-windows-x64.zip，运行 CodingAgent.exe；源码运行需 Python 3.11 及以上版本，安装仓库依赖、设置环境变量 DEEPSEEK_API_KEY 后执行 python start_gui.py。

特色功能：
这是一个基于 DeepSeek 原生 Tool Calling、自行实现运行框架的本地编程智能体，不使用 Agent 框架、服务端文件工具或远程代码执行。模型负责决策；框架自行管理对话与上下文、解析和校验工具调用、执行本地操作、回灌结果，并控制循环终止、最大步骤和连续错误上限，形成多步闭环。

工具注册表统一管理描述、参数模式、校验、执行和输出限额，支持浏览、搜索、分段读取、创建和精确编辑文件、运行命令。无效参数、文件缺失、编辑歧义、非零退出及超时均作为环境反馈返回模型，供其修正下一步。修改后记录未验证状态；若模型未经测试、构建、静态检查或程序运行便结束，验证门要求继续验证，确无可行方式时可说明原因。

会话持久化完整界面记录、模型上下文、工作区和设置，重启后可继续原有任务；两类历史分开管理。写入采用会话内锁、唯一临时文件、原子替换和有限重试，短暂失败单独提示并在后续事件重试，不把已成功的环境操作误报为智能体失败。

长会话不简单截断。超出软预算时，先压缩旧的大型只读工具结果并保持调用、结果配对及协议字段；仍超预算再将旧轮次合并为滚动摘要，保留近期轮次和当前任务。摘要成功后才移除历史，失败则保留原上下文；摘要随会话恢复，界面记录不受模型预算影响。

不同会话拥有独立上下文、工作线程、状态和事件，可同时在后台运行且不会串线。协作式停止仅在模型或完整工具调用组后的安全边界生效，不强制中断单个写入，并保留有效上下文。

每个会话可选择开启子代理。主代理最多并行委派四项独立只读调查；子代理使用新模型实例和独立上下文，只能浏览、读取和搜索，不能修改、执行命令或继续委派。内部轨迹不进入主上下文，只返回压缩结论；主代理等待同批结果后统一决策、修改和最终验证，既能并行调查，也避免多代理写入冲突。

其它说明：
文件路径和命令工作目录限于授权工作区，拒绝绝对路径、父目录越界和可解析的符号链接逃逸；凭据文件不可读取。API Key 只进入模型客户端，不写入会话或工作区，子进程会过滤常见密钥变量。命令以 shell=False 执行，设有超时、输出截断和危险操作限制。这些是基础执行边界，并非操作系统级 Sandbox；目标程序仍继承当前用户权限，同一工作区并发写入也无自动冲突解决。
